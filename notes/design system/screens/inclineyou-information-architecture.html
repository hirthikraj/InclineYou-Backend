02 · What was missing, and where it went

Every item on the old gap list is now drawn. The order below is the order it was built in — the critical path first.

1 · Workout logging · FR-4 · FR-5

Six nodes, 15 frames, a new file. The floor screen — held between sets, fully offline, used more than every other screen combined. The set table and rest timer already existed; what was missing was everything around them: the note on a set, the next-set state, the queued tick, RPE, the record moment and the docked action. inclineyou-workout-log.html

2 · Client role · FR-11

Seven nodes, 14 frames, a new file. Four tabs and no centre action, because a client has no equivalent of the trainer's create button. Governed by one rule from the design system — there is no second design system: same tokens, same components, different composition and a warmer voice. Includes the no-plan-assigned first run. inclineyou-client-role.html

3 · The client file · FR-1

Five nodes, 11 frames. Every screen that said “tap a client” now arrives somewhere: intake, the file shell with its four tabs, edit, pause-versus-archive-versus-remove, and append-only body metrics. Appended to inclineyou-clients.html — 16 frames to 27.

4 · Reports out · FR-10

The weekly report as a document, share-on-demand, and nudge delivery state — including the honest part: with WhatsApp as the channel, “sent” means handed to WhatsApp, not read. In inclineyou-drawer-pages.html.

5 · Editors · FR-3 · FR-6

The template builder is now authorable on a phone — a day at a time, not a 12-week program, which stays a desktop job by design. The exercise library gained a pick mode. The pack editor shows its arithmetic while you type it and states what a price change will not touch.

6 · Sync queue · FR-8

Every Queued tag in the app now links somewhere. Grouped by kind, oldest first, every row carrying its age and the reason it hasn't gone — and a blocked write offers a resolution rather than a bare Retry, because a conflict must never silently pick a winner.
